API END POINTS :

Authentication

Method	Endpoint	      Description

POST	/api/auth/register	Register new user
POST	/api/auth/login	Login user
POST	/api/auth/verify-otp	Verify OTP
POST	/api/auth/resend-otp	Resend OTP
POST	/api/auth/forgot-password	Forgot password
POST	/api/auth/reset-password	Reset password
GET	/api/auth/me	Get current user

Events

GET	/api/events	Get all events
GET	/api/events/:id	Get single event
POST	/api/events	Create event (Manager)
PUT	/api/events/:id	Update event (Manager)
GET	/api/events/:id/seats	Get event seats
GET	/api/events/organizer	Get organizer events
GET	/api/events/:id/summary	Event summary

Seats

POST	/api/seats/hold	Hold a seat
POST	/api/seats/release	Release a seat
GET	/api/seats/event/:eventId	Get event seats

Bookings

POST	/api/bookings	Create booking
GET	/api/bookings	Get user bookings
GET	/api/bookings/:id	Get single booking
DELETE	/api/bookings/:id	Cancel booking

Admin

POST	/api/admin/venues	Create venue
GET	/api/admin/venues	Get all venues
PUT	/api/admin/venues/:id	Update venue
DELETE	/api/admin/venues/:id	Delete venue
GET	/api/admin/users	Get all users
PATCH	/api/admin/users/:id/toggle	Toggle user status
GET	/api/admin/stats	System statistics

Waitlist

POST	/api/waitlist/join	Join waitlist
GET	/api/waitlist/event/:eventId	Get waitlist status
GET	/api/waitlist/:eventId/position	Get user position
